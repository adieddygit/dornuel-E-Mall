# DigiMall E-Commerce

# 🛒 DigiMall

DigiMall is a modern, scalable e-commerce product catalog built with React, TypeScript, Redux, and Tailwind CSS.  
It enables users to browse, filter, and sort products efficiently while delivering a smooth and responsive user experience across devices.

---

## 📌 Project Overview

DigiMall simulates a real-world e-commerce platform where users can explore products dynamically fetched from an API.  
The project emphasizes frontend best practices such as performance optimization, state management, and responsive UI design.

---

## 🎯 Project Goals

- Fetch and display product data dynamically from APIs
- Improve product discovery using filtering and sorting
- Optimize performance with pagination and infinite scrolling
- Build a responsive and accessible user interface
- Apply real-world frontend engineering standards

---

## 🧩 Real-World Application

This project mirrors challenges faced in production e-commerce systems, including:

- Managing complex UI state with Redux
- Handling large datasets efficiently
- Balancing performance with user experience
- Writing scalable and maintainable frontend code

## ✨ Key Features

### 1️⃣ API Data Integration

- Dynamic product fetching from a backend API
- Loading and error state handling
- Resilient UI for network failures

### 2️⃣ Filtering & Sorting

- Category-based product filtering
- Price sorting (ascending / descending)
- Multi-criteria filtering for refined searches

### 3️⃣ Pagination & Infinite Scrolling

- Page-based navigation for large product lists
- Infinite scrolling for enhanced user experience
- Optimized rendering for performance

### 4️⃣ Responsive Design

- Fully responsive across desktop, tablet, and mobile
- Mobile-first layout approach
- Seamless navigation on all screen sizes
